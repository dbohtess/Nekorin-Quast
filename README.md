# Nekorin Quest V1

A private gamified life dashboard for Sultan.

## V1 features

- XP and level progress
- Daily quests
- Habit streaks
- Focus timer
- Projects and progress
- Monthly calendar
- Statistics
- Responsive phone, tablet, laptop and desktop layout
- Local browser storage
- Electronic reminder sound ⚡

## Run

Open `index.html` with Live Server in Codespaces, or publish the repository with GitHub Pages.
